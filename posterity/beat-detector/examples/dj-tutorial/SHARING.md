# Tutorial audio provenance and sharing notes

These tracks are original DJ-tutorial examples generated for this project with Google Lyria 3.5 through the paid Gemini API, using newly written instructional prompts/lyrics. No reference recording, third-party lyric sheet, or artist/voice imitation was requested. The audio is AI-generated; it is not a recording of an identified human performer. These notes are provenance, not a claim that generation proves exclusive copyright or guarantees absence of similarity to existing works.

## Intended distribution

The project author requested that the finished samples be bundled as default tracks and shared with the project's source. The files are ordinary static media: visitors do not need a Google account or API key, and opening the Example folder does not generate music or incur generation charges. No credential, private API response, or local filesystem path should be published with them.

Google's Gemini API Additional Terms, under **Use of Generated Content**, state: "Google won't claim ownership over that content." The same section says Google may generate the same or similar content for others and that the user remains responsible for use and sharing. This supports using generated output as project samples, subject to applicable law and other rights; it is not a warranty of exclusive ownership, copyrightability, or universal redistribution clearance. The project's root MIT license is unchanged. This note does not invent an exclusive copyright or an additional third-party license grant.

Google's API Terms require applicable documented attribution and prohibit misrepresenting source or removing proprietary notices. The music guide says generated audio contains a SynthID watermark. No watermark removal is requested or intended. Audio processing, if documented in the set README, is for musical timing, loudness, or file metadata, not provenance removal. No Google endorsement is implied.

Before public release, listen to the final tracks and review any unexpected familiar melody or lyric. AI output can be similar to another work even when a prompt is original.
