Engines, privacy & licensing

Only two engines: Essentia.js 0.1.3 Degara (default) and music-tempo 1.0.3 (BeatRoot JS, MIT). Both receive the same mono 44,100 Hz prefix; configured tempo-induction range 40–208 BPM. Neither supplies a meaningful confidence value. Compare compute/startup times for the same window; total time may include decoding on the first run. BPM agreement is not evidence of correct beat phase.

All analysis code and WASM are served locally from this directory. Audio stays in this browser. Cancellation terminates either disposable analysis worker; browser-native decoding cannot be interrupted, so its result is discarded and a new decode waits for it to finish.

Not cleared for public distribution.
